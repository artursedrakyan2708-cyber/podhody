# Дневник подходов

Мини-приложение для Telegram: дневник силовых тренировок. Записывайте разминку и рабочие подходы, а приложение подскажет, когда пора добавить вес, и покажет прогресс.

Открыть: [@cocochalka_bot](https://t.me/cocochalka_bot) или сразу [приложение](https://t.me/cocochalka_bot?startapp). Адрес страницы: https://artursedrakyan2708-cyber.github.io/podhody/

Всё приложение — один файл `index.html`. Сервер не нужен: страница размещена на GitHub Pages, а записи хранятся в облачном хранилище Telegram у каждого пользователя.

## Возможности

- Готовые программы на выбор при первом запуске: фулбади на 2 или 3 дня, верх/низ на 4 дня или пустой план.
- Свой план: от 1 до 5 дней со своими названиями, для каждого упражнения задаются число рабочих подходов, диапазон повторов, шаг веса и время отдыха.
- Подсказка прогрессии: когда во всех рабочих подходах набран верх диапазона повторов, вес растёт на шаг.
- Таймер отдыха с виброотдачей, рекорды веса и расчётного 1ПМ, оценка «легко / нормально / на пределе».
- Заметки к упражнениям (например, настройки тренажёра).
- Графики по упражнениям, объём тренировок, календарь на 8 недель, цель на неделю, вес тела.
- Копирование таблицы для Excel и Google Таблиц, резервная копия и восстановление из неё.

## Данные и приватность

- Записи хранятся в [Telegram CloudStorage](https://core.telegram.org/bots/webapps#cloudstorage): у каждого пользователя своё хранилище, доступное только ему внутри этого бота.
- Приложение никуда не отправляет данные: у него нет сервера, аналитики и сторонних счётчиков.
- Внешние ресурсы: скрипт Telegram Web App (`telegram.org`) и шрифты Google Fonts.
- Лимиты Telegram: до 1024 записей на пользователя, до 4096 символов в каждой. Одна тренировка занимает одну запись, так что места хватит примерно на 900 тренировок.
- Если удалить бота, данные пользователей, скорее всего, пропадут. Поэтому в приложении есть резервная копия: «Обзор → Данные».

## Как опубликовать

### 1. Разместить на GitHub Pages

1. Создайте публичный репозиторий и загрузите в него `index.html` и этот `README.md`.
2. Откройте **Settings → Pages**. В **Build and deployment → Source** выберите **Deploy from a branch**, затем ветку `main` и папку `/ (root)`. Нажмите **Save**.
3. Через 1–2 минуты приложение будет доступно по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Открытая в обычном браузере страница работает в тестовом режиме: записи хранятся только в этом браузере.

### 2. Подключить к боту

1. В [@BotFather](https://t.me/BotFather) создайте бота командой `/newbot`.
2. `/mybots` → ваш бот → **Bot Settings → Configure Mini App → Enable Mini App** → отправьте адрес из GitHub Pages. После этого в профиле бота появится кнопка запуска приложения.
3. По желанию: **Bot Settings → Menu Button** → тот же адрес и подпись «Тренировка». Тогда кнопка будет и рядом с полем ввода сообщения.
4. Оформление бота: `/setuserpic` (иконка), `/setdescription`, `/setabouttext`. Готовые тексты ниже.

Ссылки, которыми можно поделиться:

- бот: `https://t.me/cocochalka_bot`
- сразу приложение: `https://t.me/cocochalka_bot?startapp`

## Как обновлять

1. В репозитории нажмите **Add file → Upload files** и загрузите новый `index.html` с тем же именем.
2. Нажмите **Commit changes**. Через 1–2 минуты обновление появится у всех пользователей.
3. Если Telegram показывает старую версию, закройте приложение и откройте снова.

Записи пользователей при обновлении не пропадают: они хранятся в Telegram, а не в файле. При правках кода не меняйте формат хранения (ключи `s_…`, `cfg_…`, `n_…`, `b_…`), иначе старые записи перестанут читаться.

## Формат хранения

| Ключ | Что хранит |
|---|---|
| `s_<дата>_d<день>` | одна тренировка: `{v:2, d, y, e:{упражнение:[ощущение, вес разминки, повторы разминки, вес1, повторы1, …]}}` |
| `cfg_plan` | настройки, порядок и названия дней, архив упражнений |
| `cfg_day<N>` | упражнения дня N |
| `n_<упражнение>` | заметка к упражнению |
| `b_<год>` | вес тела за год: `[[дата, кг], …]` |
